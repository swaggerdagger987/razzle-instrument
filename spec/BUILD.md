# Build order

No dates. A step is done only when a number on screen moves because of it. Do not start the next step before that.

1. Player-sheet tear sheet with a leverage rating. Finance language on top. One click shows the football inputs.
2. Formula builder and the open odds engine. Must pass the two-guts test in `ACCEPTANCE.md` before any polish.
3. The user's own roster, with championship odds as the hero number, and one flag that clicks through to the sheet.
4. Trade simulator. One trade shows every team's championship odds move.
5. Lab views. Scatter, heat, radar. Only stats that pair.
6. War Room last. Quiet unless the event is urgent and actionable.

Explicitly out until the instrument works: agent visuals, the full chat, college depth beyond screener coverage, cosmetic polish.

The live site and `razzle-hq` are reference, not a base to extend. This repo does not import that shell.
